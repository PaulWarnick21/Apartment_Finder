# Vancouver neighbourhood boundaries

`vancouver-neighbourhoods.geojson` was downloaded on 2026-11-14 from the City of Vancouver's [Local area boundary dataset](https://opendata.vancouver.ca/explore/dataset/local-area-boundary/), using its public GeoJSON export. It contains the City's 22 local planning areas and is licensed under the [Open Government Licence — Vancouver](https://opendata.vancouver.ca/pages/licence/).

Contains information licensed under the Open Government Licence – Vancouver.
The City does not endorse this application. Neighbourhood membership is derived from an address match, not proof of unit location, view, walking time, or airport access. Geographic distance tiers are application preferences, separate from the official boundaries.
