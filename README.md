# Apartment Finder

A personal apartment-search assistant for Vancouver: discover new rentals, filter and score
them against private criteria, remove duplicates, and manage promising homes in a Sorting
Desk through to signing a lease.

The planned application is a standalone private web app with a background scanner. It runs
independently of a coding assistant or chat session.

## Status

Planning only; no application code yet. On 2026-11-11, the user confirmed direct listing
discovery, explainable scoring, and a persistent Sorting Desk as the product direction.
